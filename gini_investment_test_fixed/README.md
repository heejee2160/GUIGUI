# 기니와 함께하는 투자 성향 탐색기

첨부된 기니 캐릭터 PNG 4개를 사용한 **Streamlit 투자 성향 테스트**입니다.

## 실행 방법

1. 압축을 풀고 터미널에서 `gini_investment_test` 폴더로 이동합니다.
2. 패키지를 설치합니다.
   ```bash
   python -m pip install -r requirements.txt
   ```
3. 앱을 실행합니다.
   ```bash
   python -m streamlit run app.py
   ```
4. 브라우저에서 표시된 로컬 주소(일반적으로 http://localhost:8501)를 엽니다.

## 구성

- `app.py` : 질문, 점수 계산, 추천 규칙, 화면 및 CSS
- `assets/부자기니.png` : 시작 화면
- `assets/고민기니.png` : 질문 화면
- `assets/성공기니.png` : 결과 화면
- `assets/포인트.png` : 상단 진행 마커

## 기능 및 점수 정의

- 시작 화면 + 10문항 + 결과 화면 / 총 12칸의 상단 진행 바로 표시
- 이전 버튼을 이용한 답변 수정 및 세션 상태 유지
- 손실 감내(4문항), 재무적 여력(2문항), 투자 기간(2문항), 유동성 관련(2문항) 응답 점수
- 각 답변 0~3점의 평균을 100점 만점으로 변환하여 **문항 응답 경향**으로 표시 (실제 투자 위험의 객관적 측정치는 아님)
- 손실 감내와 재무적 여력 중 작은 점수, 기간 및 유동성의 제약을 반영해 추천 분류를 산출
- 적합 상품 **유형 예시**, 추천 근거, 유형별 주요 위험 및 응답 상세 노출
